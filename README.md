# Estruturas de Dados

Repositório destinado ao acompanhamento da disciplina de **Estruturas de Dados**, contendo códigos desenvolvidos durante as aulas, exercícios, listas de atividades e anotações relacionadas ao conteúdo estudado.



---

## Sobre

Este repositório tem como objetivo centralizar os materiais e implementações desenvolvidos ao longo da disciplina, servindo também como registro da evolução dos conteúdos estudados.

Os exemplos e exercícios são desenvolvidos principalmente em **C**, com foco na compreensão dos conceitos de estruturas de dados, gerenciamento de memória e algoritmos.

---

## Tecnologias
